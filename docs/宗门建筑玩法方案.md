# 宗门建筑玩法方案

把宗门地图上的 49 座建筑从「贴图」变成「设施」：平时产出与养成，进去有交互，权限按职位分层。

---

## 一、三层骨架

| 层 | 定位 | 挂接的现有系统 |
|---|---|---|
| 经营养成 | 建筑是可升级设施，日产资源、养弟子、抬宗门等级 | management.industries、treasury、consumption |
| 探索交互 | 点地图格子进建筑，触发小玩法与 AI 事件 | crafting、BattlePanel、heritage、promptBuilder |
| 身份权限 | 职位决定能进哪些建筑、能做哪些事 | positions 职位树、player.position |

核心原则：建筑是载体，数值走现有管线，叙事交给 AI。不新造一套平行系统。

## 三、统一建筑模型

每座建筑实例带这几样，落进 SectIndustry 并补字段：

- 等级 Lv.1–5，升级消耗灵石与材料，越高产出越多
- 管事：绑定一位 NPC 或对应堂口，无主则产出打折
- 状态：正常 / 修缮中 / 停用，停用则产出归零
- 日产与日耗：汇入每日结算
- 解锁条件：要求职位 + 宗门等级，未达则显示但不可用

---

## 四、资源与产出链

新增四种材料，接进 treasury.materials：

灵田产药材、灵谷、蔬菜；锻器类产矿石；丹房用药材出丹药；锻器用矿石出兵刃；灵苑出灵兽。

闭环：种 → 炼 / 锻 → 装备与丹药 → 强化弟子 → 更快产出。灵谷与蔬菜走日耗，喂养全体弟子，低于阈值则忠诚下滑。

## 六、词条联动

| 词条 | 作用 |
|---|---|
| nature 宗门性质 | 主产类倾斜。丹修门丹房产出加成、升级更便宜，与已有 applySectFeatureBias 布局倾斜是一条线 |
| feature 特殊资源 | 特色建筑升格为镇门之宝：独有交互、独有产出、外敌来犯时优先被夺 |
| culture 文化圈 | 独有建筑只在对应文化圈出现，带文化独有交互 |
| climate 宗门风气 | 影响弟子日常与随机事件。严整如军训练快但忠诚易掉；清谈问道参悟快而战力弱；好勇斗狠演武加成但外交差 |

## 七、每日结算

日结顺序：各建筑产出入宝库 → 扣维护费 → 弟子耗灵谷与蔬菜 → 忠诚变动 → 建筑可能入修缮 → 生成当日 AI 叙事摘要。对应现有的 consumption.dailyCost 与 settledDay。

---

## 八、界面入口

地图点格子 → 浮出建筑卡，显示名称、等级、日产、管事 → 点「入内」开建筑面板，三页：

1. 经营页：等级、日产、维护、升级
2. 交互页：该建筑可做的事，按职位过滤
3. 叙事页：按「建筑 + 四词条 + 玩家职位」拼提示词，AI 现写一段剧情

---

## 九、分期实施

1. 一期 经营层：建筑等级数据 + 点格开卡 + 升级/产出/日结
2. 二期 交互层：每类建筑一个动作面板，接 crafting、battle、heritage
3. 三期 权限层：职位门控 + 各堂管事 NPC 绑定
4. 四期 词条联动与 AI 叙事增强

## 十、本期实施范围

本期先做「交互层」的三件事，均落在宗门系统内。

### 1. 主殿 · 每日开讲

- 每日固定时辰开讲，时间点写进宗门数据，可随宗门配置不同。
- 玩家身处宗门地图内时，开讲前给出提前提醒。
- 掌门开讲不消耗自身修为；弟子上课效果取决于掌门的修为高低，修为越高，弟子涨的修为越多。
- 玩家连续超过半个月未参加开讲，小幅扣除贡献点。

### 2. 经阁类 · 贡献换功法 / 讲经换贡献

- 经阁类建筑可用贡献点换取学习新功法，能否学、能学什么由身份等级决定。
- 讲经堂可主动讲经，换取贡献点，收益随身份等级与经阁等级变化。

### 3. 宗门任务 · 改为真实可完成任务

- 现有门派任务只是「点接取即结算」，改为真正可完成的任务。
- 仿牙行任务的做法：生成任务 NPC、任务地点、目标与交付条件，玩家需实际前往或交付才算完成。
- 完成后结算贡献与灵石，与任务板状态联动。
